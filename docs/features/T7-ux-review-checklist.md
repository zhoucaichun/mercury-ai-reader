这份清单由 T7 在每周集成后维护。目标是及时发现影响课堂演示、阅读舒适度和功能可发现性的问题。

## 2. 阅读流程

- [ ] 应用启动后能看到文章列表。
- [ ] 用户能清楚判断文章列表处于加载、空状态还是失败状态。
- [ ] 点击文章后能打开阅读器视图。
- [ ] 当前选中文章在列表中有明显视觉区分。
- [ ] 阅读器视图展示标题、来源、发布时间和原文链接。
- [ ] 阅读器正文使用 cleaned 内容，而不是 raw source 噪声内容。
- [ ] 长文章阅读时仍然舒适。

## 3. 阅读设置

- [ ] 字号设置容易找到。
- [ ] 行距设置容易找到。
- [ ] 主题设置可用，或明确标记为后续实现。
- [ ] 阅读宽度设置可用，或明确标记为后续实现。
- [ ] 修改阅读设置不会破坏页面布局。
- [ ] 用户能理解当前设置，也能方便恢复或继续调整。

## 4. AI 与导出入口

- [ ] Summary 摘要入口在阅读器中清楚可见。
- [ ] 摘要卡片能展示 Runtime 状态：idle / queued / running / succeeded / failed / cancelled。
- [ ] 摘要卡片包含重新生成、复制、清除操作。
- [ ] Translation 翻译入口在阅读器中清楚可见。
- [ ] Export Markdown 导出入口在阅读器中清楚可见。
- [ ] 禁用或 mock 状态的按钮能说明当前状态。
- [ ] AI 操作的命名和样式保持一致。
- [ ] T9 提供 Usage 面板后，用量统计入口容易发现。
- [ ] Provider 配置入口能清楚表达 base URL / API key / model 的配置状态。
- [ ] Usage 面板能展示调用次数、成功 / 失败、token 估算和最近调用明细。
- [ ] 多模型测试或模型切换入口不干扰正文阅读。

## 5. 状态与错误体验

- [ ] 空文章列表有有帮助的提示。
- [ ] 文章正文为空时有有帮助的提示。
- [ ] 网络错误或同步错误提示容易理解。
- [ ] 需要时提供重试操作。
- [ ] 加载状态看起来不像页面损坏。
- [ ] 错误信息避免暴露技术栈或长堆栈信息。

## 6. 视觉一致性

- [ ] 按钮、图标和间距保持一致。
- [ ] 阅读器工具栏不会挤压正文内容。
- [ ] 文章列表便于快速扫描。
- [ ] 文本没有溢出或重叠。
- [ ] 浅色和深色界面都有足够对比度。
- [ ] 页面在常见笔记本屏幕尺寸下观感正常。
